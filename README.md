# 💀 Fake BSOD Prank

A realistic Blue Screen of Death simulator built with Avalonia UI for harmless pranks.

![Platform](https://img.shields.io/badge/Platform-Windows%20%7C%20macOS%20%7C%20Linux-blue)
![.NET](https://img.shields.io/badge/.NET-6.0+-512BD4)
![License](https://img.shields.io/badge/License-MIT-green)

## Features

- 🎯 Authentic Windows BSOD appearance
- 🔄 Consistent MEMORY_MANAGEMENT error display
- ⌨️ Multiple exit shortcuts for safety
- 🖥️ Fullscreen overlay
- 🏗️ Clean MVVM architecture

## Quick Start

```bash
# Clone the repository
git clone git@github.com:amuza2/BlueScreenofDeath.git

# Navigate to project
cd BlueScreenofDeath

# Run the application
dotnet run
```

## Usage

1. Click **"Trigger Prank"** button
2. Watch the realistic Blue Screen appear
3. Exit using any of these shortcuts:
   - `Ctrl + Shift + Q`
   - `Ctrl + Alt + W`
